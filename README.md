# cloud-sec-labs

クラウドセキュリティ演習用のファイルです。 / Files for the cloud security labs.

## Lab 9

`lab9/lab9-incident.yaml` は Lab 9 で使う CloudFormation テンプレートです。

1. Cloud9 のターミナルで次を実行します。

   ```
   git clone https://github.com/tlaskowsky/cloud-sec-labs
   ```

2. 左のファイル一覧で `cloud-sec-labs/lab9/lab9-incident.yaml` を右クリックし、**Download** を選びます。
3. ダウンロードしたファイルを CloudFormation のビジュアルエディター（Infrastructure Composer）に読み込みます。手順は講師の指示に従ってください。

すでに clone している場合は、`cloud-sec-labs` フォルダで `git pull` を実行すると最新になります。
